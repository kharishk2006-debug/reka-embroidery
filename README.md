# REKA Embroidery & Tailoring — Premium Website

A modern, elegant, and responsive website developed for **REKA Embroidery & Tailoring**, showcasing custom blouse stitching, embroidery services, tailoring work, customer reviews, and premium boutique-style presentation.

## ✨ Features

- Premium boutique-style UI/UX
- Responsive design for desktop, tablet, and mobile
- Custom blouse stitching showcase
- Embroidery and tailoring service sections
- Customer work gallery
- Customer review submission system
- Admin review management dashboard
- Review approval and deletion functionality
- SQLite database for storing customer reviews
- Smooth hover and scroll animations
- English-only customer-facing interface
- WhatsApp contact integration
- Social media integration
- SEO-friendly semantic HTML structure

## 🛠️ Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite
- **Icons:** Font Awesome
- **Fonts:** Google Fonts
- **Deployment:** Vercel
